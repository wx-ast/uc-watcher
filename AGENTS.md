# Инструкции по сопровождению UC Watchdog

## Назначение и структура

Это нативный пользовательский агент macOS, восстанавливающий Universal Control
после подтверждённой потери доступности конкретного Mac.

- `Package.swift` — описание SwiftPM-пакета и минимальной версии macOS.
- `Sources/UCWatchdog/main.swift` — монитор журнала, ограничения восстановления,
  выбор процессов, установщик приложения и встроенные проверки.
- `Sources/UCWatchdog/MenuBar.swift` — меню, системный автозапуск и управление процессом монитора.
- `Sources/UCWatchdog/PeerDiscovery.swift` — поиск IDS-префиксов в журнале и выбор устройства при установке.
- `Sources/UCWatchdog/RecoveryNotice.swift` — стандартные уведомления macOS через UserNotifications.
- `Sources/UCWatchdog/Resources/AppIcon.icns` — иконка приложения; исходное изображение в `Assets/AppIcon.png`.
- `README.md` — сборка, установка, ограничения и управление.

Используйте Swift и системные Foundation/Darwin. Для этой программы не нужны
Python, сторонние зависимости, root-процесс или изменения SIP.
Для уведомлений используется системный UserNotifications; AppKit обслуживает главный цикл приложения.

## Инварианты

1. Реагировать только на точный IDS-префикс настроенного исходного Mac.
2. Один `Device Lost` не должен вызывать перезапуск. Триггер восстановления —
   `Device Unavailable`, если требования явно не изменены пользователем.
3. Сохранять защиту от циклов: одна попытка на исчезновение, cooldown 120 секунд,
   не более трёх попыток за 600 секунд, история между запусками.
4. Отправлять сигналы только процессам текущего UID с точными путями исполняемых
   файлов. Перепроверять PID перед сигналом; исключать службы симуляторов.
5. Режим `--dry-run` и команды проверки не отправляют сигналы службам.
6. Поддерживать блокировку единственного экземпляра и ограниченную ротацию журнала.
7. Не менять настройки Bluetooth/VPN и не отключать SIP для обхода ошибок.
8. При обновлении сохранять историю восстановления и журналы. Удаление агента
   сохраняет диагностические файлы.
9. Сообщать об успешном восстановлении только после `Connected` для целевого Mac.
   `Device Available` означает обнаружение, а не восстановление ввода.
10. Использовать стандартные уведомления macOS из `.app` с постоянным bundle ID.
    Не перехватывать фокус; показом и удалением управляет Центр уведомлений.
    `--dry-run` не запрашивает разрешение на уведомления и не отправляет их.

## Проверки изменений

```sh
swift build -c release
.build/release/uc-watchdog self-test
.build/release/uc-watchdog check-processes
```

Для изменений чтения журнала дополнительно проверить `monitor --dry-run --duration 30`
на macOS. Для изменений установщика проверить установку/обновление, статус и
удаление в подходящей среде. Эти действия меняют пользовательский объект входа и могут удалить старый LaunchAgent.
Не считайте успешную сборку доказательством ускорения восстановления: это проверяется
отдельно по естественному обрыву и журналам обоих Mac.

## Текущий контекст

Принимающий Mac доступен по `ssh mbl`, исходный IDS-префикс — `3047DD83`.
Приложение установлено на mbl с bundle ID `local.uc-watchdog`. Автозапуск через
`SMAppService.mainApp`; старый LaunchAgent с тем же label удаляется при обновлении.
Исследованные обрывы начинались с потери BLE-обнаружения, затем через 45 секунд
Universal Control удалял удалённые устройства ввода. В отдельных эпизодах AWDL-канал
оставался открытым. Сбой воспроизводился без VPN и Bluetooth-наушников.
Первопричина потери обнаружения пока не доказана.

Каталог этого проекта — основной источник кода. Артефакты предыдущего чата
служат историческими сборками. Изменение исходника не означает обновление
установленного агента; отмечайте факт установки отдельно в отчёте.
